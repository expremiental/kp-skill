# Профиль бренда отправителя

Документ уходит от имени пользователя, а не от нашего. Значит выглядеть он должен как документ его компании, а не как документ, собранный генератором.

Пять ручек в шапке шаблона: шрифт, акцентный цвет, скругления, форма паттерна, вес заголовков.

> **Четыре из пяти снимаются с сайта измерением, а не подбираются по вкусу.**
>
> Не угадывай профиль по отрасли — это гадание. «B2B-консалтинг, значит строгий шрифт и острые углы» звучит правдоподобно и ошибается. На проверке одной такой компании оказалось: заголовки набраны нейтральной гротеской весом **300** — тонкие, а не плотные; карточки скруглены на **20–30px** — сильно, а не остро; вторичный цвет тёплый оранжевый. Отраслевая догадка промахнулась бы по трём параметрам из четырёх.

---

## Кто снимает и как

Скрипт читает **computed styles** — то, что браузер реально применил к странице после загрузки всех стилей и шрифтов. Скачать HTML и распарсить это не заменяет: на сайтах-конструкторах и SPA половина стилей приезжает скриптами, а у части сайтов заголовочных тегов нет вовсе.

Значит нужен живой браузер. Два рабочих пути, выбирать по обстановке.

### Путь 1. Агент сам, через браузер

Если у пользователя подключено управление Chrome — агент открывает сайт отправителя новой вкладкой, выполняет скрипт, забирает JSON, закрывает вкладку. Человек ничего не делает.

**Сначала спроси разрешения:** «Схожу на ваш сайт снять фирменный стиль — открою вкладку в браузере, ок?» Открывать браузер молча нельзя, это действие вовне.

### Путь 2. Человек сам, за 30 секунд

Универсальный вариант — работает у всех, никаких расширений. Скажи ровно так:

> Открой сайт своей компании → нажми F12 (на Mac ⌥⌘I) → вкладка Console → вставь скрипт → Enter → скопируй мне результат.

Скрипт дай одним блоком. Ответ придёт JSON-ом, разбери его по таблице ниже.

### Чего не делать

**Не пытаться снять профиль, скачав страницу curl'ом или через fetch.** Computed styles так не получить: вернётся исходный HTML без применённых стилей. Молчаливая деградация — хуже отсутствия профиля, потому что цифры будут, а верить им нельзя.

### Если ни один путь не сработал

Ставь дефолт шаблона и **скажи человеку прямо**: профиль по умолчанию, потому что снять не получилось, документ будет в нейтральном стиле. Не выдумывай фирменный стиль по названию компании.

## Скрипт

Он читает computed styles — то, что реально применилось, а не то, что написано в исходниках.

```js
(() => {
  const cs = el => getComputedStyle(el);
  const hex = c => { const m = c.match(/\d+/g);
    return m && m.length>=3 ? '#'+m.slice(0,3).map(x=>(+x).toString(16).padStart(2,'0')).join('') : c; };
  const vis = el => { const r = el.getBoundingClientRect();
    return r.width>40 && r.height>18 && cs(el).visibility!=='hidden'; };
  const freq = a => { const m={}; a.forEach(v=>m[v]=(m[v]||0)+1);
    return Object.entries(m).sort((x,y)=>y[1]-x[1]).slice(0,3); };

  // 1. АКЦЕНТ — фон кнопок и CTA
  const btns = [...document.querySelectorAll(
    'button, a[class*=btn], a[class*=button], .btn, .button, [role=button], input[type=submit]')].filter(vis);
  const accent = freq(btns.map(b=>hex(cs(b).backgroundColor))
    .filter(c => c!=='#ffffff' && c!=='#000000'));

  // 2. ШРИФТ и ВЕС — по крупному тексту, а не по тегам h1-h3:
  //    на конструкторах сайтов заголовочных тегов часто нет вовсе
  const big = [...document.querySelectorAll('*')].filter(el => {
    const s = cs(el), r = el.getBoundingClientRect();
    return r.width>60 && el.children.length===0 && el.textContent.trim().length>3
        && parseFloat(s.fontSize) >= 26;
  }).slice(0,120);
  const font   = freq(big.map(e=>cs(e).fontFamily.split(',')[0].replace(/["']/g,'')));
  const weight = freq(big.map(e=>cs(e).fontWeight));

  // 3. СКРУГЛЕНИЯ — по кнопкам и карточкам
  const cards = [...document.querySelectorAll('div,section,article')].filter(el =>
    vis(el) && parseFloat(cs(el).borderTopLeftRadius) > 0
    && el.getBoundingClientRect().width < 700).slice(0,120);

  return JSON.stringify({
    акцент:            accent,
    шрифт_заголовков:  font,
    вес_заголовков:    weight,
    шрифт_текста:      cs(document.body).fontFamily.split(',')[0].replace(/["']/g,''),
    подключённые:      [...document.fonts].map(f=>f.family).filter((v,i,a)=>a.indexOf(v)===i).slice(0,8),
    скругление_кнопок: freq(btns.map(b=>cs(b).borderTopLeftRadius)),
    скругление_карточек: freq(cards.map(c=>cs(c).borderTopLeftRadius))
  }, null, 1);
})()
```

**Если страница отдала `Times` и пустые списки — она не догрузилась.** Подожди и выполни ещё раз.

## Как читать результат

| Что вернулось | Куда кладётся |
|---|---|
| `акцент` — первый по частоте цвет кнопок | `--accent`. Если два цвета сопоставимы по частоте, брать тот, которым выделены **действия**, а не фон секций |
| `шрифт_заголовков` / `подключённые` | `--font`. Если шрифт платный (Circe, Graphik, TT-семейства) — взять ближайший из списка ниже |
| `вес_заголовков` | `--w-head` напрямую. Значение 300 значит тонкие заголовки — не подменяй на привычные 600 |
| `скругление_карточек` | `--radius-lg`. 0px → нули везде · 4–10px → дефолт шаблона · 16px и больше → крупные скругления |
| форма паттерна | **не измеряется.** Посмотри глазами: есть в фирменном стиле круги и дуги — кольцо; диагонали и скосы — `pat-band`; ничего выраженного — `pat-none` |

**Вторичный цвет** сайта в деку не тащим: в шаблоне уже есть красный для проблем и зелёный для результатов, третий акцент их перебьёт.

## Шрифты с кириллицей

Только то, что есть в Google Fonts и умеет русский:

| Шрифт | Характер |
|---|---|
| **Inter** | нейтральный, чуть технический — дефолт |
| **IBM Plex Sans** | строгий, инженерный |
| **Manrope** | мягкий, округлый |
| **Golos Text** | сдержанный, современно-русский |
| **Onest** | геометричный, нейтральный |
| **Unbounded** | характерный, только для заголовков и только в паре с нейтральным для текста |

Подключается `@import` в шапке шаблона, ставится в `--font`.

## Если сайта нет

Только тогда — готовые сочетания. **Это заглушки, а не рекомендации по отрасли.** Возьми любое, которое не спорит с тем, что человек рассказал о себе, и скажи ему, что профиль поставлен по умолчанию, потому что снять было неоткуда.

- **Нейтральное** — `Inter`, скругления 4mm, кольцо, вес 600. Дефолт шаблона.
- **Острое** — `IBM Plex Sans`, скругления 0, `pat-band`, вес 600.
- **Мягкое** — `Manrope`, скругления 7mm, кольцо, вес 800.
- **Спокойное** — `Golos Text`, скругления 2mm, `pat-none`, вес 500.

## Чего не делать

- **Не угадывать профиль по отрасли.** Меряй.
- **Не красить в цвета получателя.** Документ отправляет наша сторона; цвета клиента в чужом КП выглядят как подражание.
- **Не тащить логотип из интернета.** Место под него в шаблоне есть, файл подставляет человек.
- **Не смешивать больше двух шрифтов.**
- **Не менять профиль между версиями одного КП.** Клиент получил синюю деку — вторая версия тоже синяя.
