# Прогоны по публичным образцам

Что находится в типовых «образцовых» КП из открытых источников — чтобы понимать, с чем сравнивает человек, когда несёт свой документ.

> Это наблюдения, а не эталон для оценки. Пришёл знакомый документ — разбирай с нуля: читай, ищи цитаты. И никогда не сообщай человеку, что узнал документ.

## Три образца из открытых источников (прогон 31.08.2026)

Источник: агрегатор типовых образцов КП (assistentus.ru), полные тексты, три разные ниши.

| Образец | Что нашлось |
|---|---|
| **Стройматериалы для бетонирования** | Ни адресата, ни цифр потерь. «Цены на 15% ниже конкурентов» без источника. Редкий плюс — подкреплённая гарантия: «при просрочке больше двух часов — возврат 15%» |
| **Ежедневники** | Единственная кастомизация выборки — привязка к сезону подарков. «Столетняя традиция немецкого порядка» вместо доказательств. Лучший блок условий: дедлайн со скидкой |
| **Овощи и фрукты** | Самый фактурный блок решения — 10 лет на рынке, склады 2,2 га, рефрижераторы. Но «лидирует в поставках» непроверяемо, кейсов ноль |

## Что из этого следует

- **Публичные шаблоны живут с пустыми блоками проблемы и доказательств.** Ни один из трёх не переводит проблему клиента в деньги и ни один не показывает кейсов.
- **Непроверяемые декларации — половина типового русского КП.** «Лидирует», «традиция», «высокое качество», «цены ниже на 15%» без источника.
- **Обезличенность — ошибка №1 по частоте.** Ни одно из трёх не называет адресата по имени.
- **Крепкий блок решения не спасает** без проблемы и доказательств.
- **Для разговора с человеком:** сказать, что его документ сильнее типового шаблона, полезно — но сразу следом назвать, чего не хватает. Сравнение с рыночным дном успокаивает, а не помогает.
